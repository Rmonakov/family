# Приватний архів

Статичний вебзастосунок із клієнтським криптографічним захистом даних та медіафайлів (**AES-256-GCM + PBKDF2-HMAC-SHA256, 600 000 ітерацій**).

## Архітектура безпеки
- **Повне клієнтське шифрування:** структуровані дані (`js/data.enc.js`) та всі медіафайли (`assets/*.bin`) зашифровані алгоритмом `AES-256-GCM` із унікальними векторами ініціалізації (`IV`).
- **Web Crypto API:** розшифрування JSON-даних і бінарних медіаконтейнерів (`Blob URL`) виконується безпосередньо в пам'яті браузера після введення парольної фрази.
- **Локальні залежності та CSP:** усі клієнтські бібліотеки (`D3.js v7`, `Leaflet 1.9`, `GSAP 3.12`, `Panzoom 4.5`, `Lucide Icons`, скомпільований `Tailwind CSS 3.4`) розміщені локально у каталозі `vendor/` під захистом суворої політики `Content-Security-Policy` (`script-src 'self'`).
- **Картографічні тайли:** інтерактивна карта завантажує офіційні растрові тайли `OpenStreetMap` (`tile.openstreetmap.org`), якому передаються стандартні HTTP-запити тайлів для поточного масштабу перегляду.

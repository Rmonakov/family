# Приватний родинний архів

Приватний інтерактивний сімейний портал із клієнтським криптографічним захистом даних (**AES-256-GCM + PBKDF2-HMAC-SHA256**).

## Технологічний стек
1. **D3.js v7 + Panzoom 4.5** — інтерактивне полотно генеалогічного дерева.
2. **Leaflet 1.9** — інтерактивна карта історичних маршрутів.
3. **Web Crypto API (AES-256-GCM)** — розшифрування архівних даних у браузері за сімейним кодом доступу.
4. **Tailwind CSS 3.4 + Lucide Icons** — адаптивний інтерфейс.
